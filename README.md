# Raahil Amaan — Portfolio

A responsive, dark premium portfolio built with plain HTML, CSS and JavaScript.

## Project structure

- `index.html` — page structure and content
- `css/style.css` — all visual styling and responsive layout
- `js/script.js` — interactions, scroll effects and interactive 3D hero
- `README.md` — project notes and deployment instructions

## Run locally

Open `index.html` in your browser, or open this folder in VS Code and use the Live Server extension.

## Deploy with GitHub Pages

1. Create a public GitHub repository.
2. Upload the contents of this folder, keeping the `css` and `js` folders in place.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Visit the GitHub Pages URL shown in the Pages settings.
